**minor** — `internal/integration/config_env_helpers_test.go:128`  
`sopsVersionRE` keeps only the first `major.minor.patch` and ignores a prerelease or extra suffix. Output `sops 3.13.1-rc1` is treated as `3.13.1` and passes the floor. The CI case at `.github/workflows/ci.yml:251` rejects that same string (it requires end-of-string or a space). Official 3.13.1 and 3.13.3 with `--disable-version-check` print `sops 3.13.3` and are unaffected. A wrapper that prints another `sops N.N.N` before the real line is also taken as the version, because the match is not anchored to line 1. `PrintVersion` in both releases writes the real version first, so official extra lines stay correct.

**minor** — `internal/integration/config_env_helpers_test.go:111`  
The skip is `dir == ""` or (basename `shims` and the path contains `mise`). An empty PATH entry is skipped. A relative PATH entry such as `bin` is not. If `bin/sops` is executable, the function returns the relative path `bin/sops`. `toolPATH` then symlinks that relative target, which resolves against the temp directory rather than the directory that was searched. A non-mise directory named `shims` (for example `~/.asdf/shims`) is still searched, so a shim there can still be returned. The default mise directory `~/.local/share/mise/shims` is skipped.
