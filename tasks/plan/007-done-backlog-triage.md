## Goal

   그 카드들은 PLAN-006이 닫는 시점에 리뷰된다. 일회성 비움은 완료됐고, 재고는 다시 채워져 §2026-09-09에서
   유량 문제로 재정의됐다(아래).
2. 리뷰 없이 아카이브한 카드는 `quality-review` 값으로 그 사실이 정직하게 남아 있다.
3. 루프가 관찰로만 남겼던 결함 3건이 자식 카드로 처리됐다.

### 2026-09-14 처분 — 컷오프는 날짜가 아니라 규칙이 생긴 커밋이다

위 방침을 집행했다. **레거시를 임의의 날짜로 가르지 않았다.** 규칙이 없던 때에 done으로 간
카드에만 waiver가 정직하고, 규칙이 있는데도 리뷰 없이 간 카드는 레거시가 아니라 부채다.
경계는 `git log -S'## Task completion review' -- AGENTS.md`가 가리키는 커밋이다:

```
1c85d8d0 2026-09-10 docs(tasks): require independent done review
```

각 카드의 done 진입 커밋(`git log --diff-filter=A`)을 이 커밋과 비교해 둘로 갈랐다:

| 구간 | 장수 | 처분 |
|---|---|---|
| `1c85d8d0` **이전**에 done 진입 | 29 | `quality-review: waived` + 카드별 진입 커밋·날짜를 근거로 기록 |
| `1c85d8d0` **이후**에 done 진입 | 8 | waiver 불가 — [[TASK-393]]이 실제 리뷰로 닫는다 |

29장의 `quality-review-evidence`는 카드마다 자기 진입 커밋을 적는다. 일괄 처분이지만
근거는 일괄이 아니다. **남은 8장은 수가 줄었다는 뜻이 아니라 성격이 바뀌었다는 뜻이다** —
"리뷰 안 됨"이라는 한 덩어리에서 "리뷰해야 하는데 안 한 것"으로. 앞의 것은 기록으로 닫히고
뒤의 것은 작업으로만 닫힌다.

### 유입 차단의 한계 — `blocks:`가 검사 조건이던 시절의 기록

[[TASK-381]]은 이 선언 **이후** done에 들어왔고 리뷰 없이 들어왔다. 원인은 [[ISSUE-015]]가
실측으로 기록했다: `ce task validate`가 영수증을 요구하는 조건이 `blocks:` 하나뿐이라는
것. TASK-381은 그 문제가 없는 케이스로 **진짜 독립 리뷰**(`review-381`, 판정
`conditional`)을 받았고 — 결함 네 형태를 독립 재파종해 rc=1로 발화, 미해결 발견은
ISSUE-016~018로 분리, 영수증은 `tasks/receipts/TASK-381/`에 있다. 리뷰가 실제 결함
여섯을 찾았다는 사실이 배분 판단(provenance가 살아 있는 카드엔 진짜 리뷰가 더 싸다)의
회수를 증명한다.

> **현행화 (2026-09-15, [[TASK-401]]).** 당시 TASK-381의 영수증 핀은 plain sha256이었고
> "`blocks:` 없어 validator가 검사에 도달하지 않으므로 정규 digest를 얻을 경로가 없다"고
> 기록했다. **두 서술 모두 폐기됐다** — 현행 런타임은 `blocks:`와 무관하게 모든 done
> 카드의 수신 핀을 검사하고, plain 핀은 통과하지 못한다. TASK-401이 11장을 정규 핀으로
> 재발행했다. 핀 규칙의 현행 판정은 [[ISSUE-001]] §pin 절이 소유한다.

### `waived`가 상류에 추가됐다 — §External 2번은 해결됐다

`ce task archive --help`가 `quality-review: pass|conditional|waived`를 받는다고 명시하고,
`waived`는 `quality-review-evidence`를 함께 요구한다 — 이 계획이 요청한 형태 그대로다.
대가가 하나 남는다. §Order 3이 Tier B 36장을 값이 없던 시절 `conditional` + evidence
문구로 우회했고, `tasks/_archive/done/`의 `quality-review: conditional`은 **48장**이다.
그중 상당수는 리뷰된 카드가 아니라 우회된 waiver다. **소급 수정하지 않는다** — evidence
문구가 각 카드에 남아 정보는 손실되지 않았다. 기록: **그 48장을 세어 "48장이 리뷰됐다"고
읽으면 틀린다.**
