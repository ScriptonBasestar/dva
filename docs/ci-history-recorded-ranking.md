# 기록된 단계 시간 순위

`dva ci history`의 `recorded_duration_ranking`은 한 실행에서 종료된 단계의
기록 시간 상위 다섯 개를 내림차순으로 표시한다. 동률은 기록 순서를 유지한다.
이 시간은 단계 배정부터 완료까지의 경과이며,
`reuse_disposition`이 `reused`면 검사 실행이 아닌 재사용 조회 시간이다. `unknown`은
실제 실행 여부를 증명하지 않는다. 원본 실행 ID가 있으면 함께 표시한다.

미완료 단계는 순위에 넣지 않는다. 성공·실패 등 상태를 유지하며, 서로 다른 실행의
시간을 비교하거나 단계 시간의 합을 전체 경과 시간이라고 주장하지 않는다.
`slowest_steps`는 실제 실행으로 명시된 단계만 포함하는 기존 순위다.
