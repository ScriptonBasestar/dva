# DVA v0.4.2

v0.4.2는 v0.4.1에 `dva version`의 commit 보고 수정 하나를 더한 patch 릴리스입니다.

## 수정

- ldflags가 commit을 넣지 않은 빌드의 `dva version`이 `commit: dev` 대신 무엇을 설치했는지
  보고합니다.
  - checkout 안의 빌드(`go install ./cmd/dva`)는 `<revision> (vcs)`를, 변경이 있던 tree면
    `<revision>-dirty (vcs)`를 보고합니다.
  - module 설치(`go install github.com/ScriptonBasestar/dva/cmd/dva@v0.4.2`)는 SHA로
    오인하지 않도록 `unknown (module v0.4.2)`를 보고합니다.
  - Release archive와 `make build`의 바이너리는 지금처럼 tag commit을 맨 SHA로 보고합니다.

## 호환성

- `dva version --json`에 `commit_source`(`ldflags`·`vcs`·`module`·`default`)가, module 설치에서는
  `module_version`이 추가됩니다. 기존 `version`·`commit`·`build_date` 필드는 그대로입니다.
  `commit`은 출처와 관계없이 SHA만 담지 않을 수 있으므로(`unknown`, `-dirty`, `dev`) SHA로 쓰기
  전에 `commit_source`를 확인합니다.
- VCS 정보가 없는 빌드(`-buildvcs=false` 등)는 계속 `dev`를 보고합니다.

전체 변경은 [CHANGELOG](https://github.com/ScriptonBasestar/dva/blob/v0.4.2/CHANGELOG.md)의
0.4.2 섹션을 따릅니다.
