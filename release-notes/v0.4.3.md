# DVA v0.4.3

v0.4.3은 `env_file` 경로 변수 확장과 plan 검증 강화를 담은 릴리스입니다. 호환성 변경이
2건 있으니 업그레이드 전에 `dva validate --strict`를 실행하세요.

## 호환성 변경

- `env_file` 경로의 `${VAR}`, `${VAR:-default}`를 `vars`, `environment:`, OS 환경 변수로
  확장합니다. 해석되지 않는 참조는 `required`와 무관하게 오류입니다.
- plan이 소유자가 선언하지 않은 environment를 가리키면 `dva validate`가 실패합니다.

## 추가와 수정

- `dva status --all`로 `default_plan`과 무관하게 전체 stack을 조회합니다.
- `dva down <plan>`, `dva stop <plan>`이 plan의 compose profile을 넘깁니다.
- plan 경로의 `dva status --json`이 JSON을 출력합니다.
- 패키지 경계 검사 등 나머지 변경은 CHANGELOG의 0.4.3 섹션을 참고하세요.

## 제거 예정

- `modes`/`default_mode`는 v0.5.0부터 스키마가 거부합니다. `dva config migrate`로 이관하세요.

## 알려진 제약

- 이 버전에서는 `${A:?x}`, `${A:+x}` 같은 미지원 문법의 `env_file` 경로가 검증을 통과해 문자
  그대로 열립니다. 경로 전체가 빈 값으로 확장되면 config 디렉터리를 열어 읽기 오류가 납니다.
  다음 패치에서 둘 다 `unresolved_path` 오류가 됩니다.
