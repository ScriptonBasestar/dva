# DVA v0.4.4

v0.4.4는 v0.4.3에서 알려진 제약으로 남겼던 `env_file` 경로 문제를 고치는 패치입니다. 지금까지
조용히 통과하던 경로가 오류로 바뀔 수 있으니 업그레이드 전에 `dva validate --strict`를
실행하세요.

## 호환성 변경

아래 `env_file` 경로는 이제 `required`와 관계없이 `unresolved_path` 오류입니다. 실행·정리·관찰
명령이 멈추고, `dva validate`가 파일을 열지 않고 미리 경고합니다.

- 지원하지 않는 문법 `${A:?x}`, `${A:+x}`: 경로에서 빼고 기본값이나 정의된 변수를 쓰세요.
- 변수 값에 든 `${`: 해당 값을 실제 경로로 바꾸세요.
- `.`, `/`로 확장되는 경로: 파일을 가리키도록 고치세요.
- 맨 앞 변수가 비어 절대 경로가 되는 `${E}/.env`, `${PREFIX}/etc/app/.env`: 절대 경로를 직접
  적거나 `${PREFIX:-/}/etc/app/.env`처럼 기본값을 지정하세요.

## 수정

- `unresolved_path` 오류가 경로 전체 대신 원인이 된 조각을 표시합니다.
- 잘못된 변수 값이 경로에 있을 때 뒤따르는 변수의 확장 값이 오류 메시지에 함께 나오던 경우를
  줄였습니다. 값이 뒤쪽 확장 텍스트 안에서 닫히는 형태는 아직 남아 있습니다.

## 알려진 제약

- `vars`나 `environment:`에서 이미 펼쳐진 값은 빈 변수 판정이 잡지 못합니다.
- `$${S}/.env`처럼 `$` 바로 뒤에 참조가 오면 없는 `$x`를 원인으로 표시하며 거부합니다.
